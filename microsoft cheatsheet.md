# CheatSheet Windows - Technicien Supérieur Systèmes & Réseaux (TSSR)

## Raccourcis Importants

### Raccourcis avec la Touche Windows (Win)

| Raccourci | Action |
| :--- | :--- |
| **Win + E** | Ouvrir l'Explorateur de fichiers |
| **Win + D** | Afficher ou masquer le bureau |
| **Win + L** | Verrouiller l'ordinateur ou changer de compte |
| **Win + V** | Ouvrir l'historique du presse-papiers |
| **Win + I** | Ouvrir les Paramètres de Windows |
| **Win + A** | Ouvrir le Centre de notifications / Réglages rapides |
| **Win + K** | Ouvrir le menu d'affichage / Connexion sans fil |
| **Win + P** | Choisir le mode de projection (écrans multiples) |
| **Win + R** | Ouvrir la boîte de dialogue *Exécuter* |
| **Win + X** | Ouvrir le menu Liens rapides (Gestionnaire de périphériques, Terminal, etc.) |
| **Win + .** (Point) ou **Win + ;** | Ouvrir le panneau d'émojis et caractères spéciaux |
| **Win + Tab** | Ouvrir l'Affichage des tâches (Bureaux virtuels) |
| **Win + Ctrl + D** | Créer un nouveau bureau virtuel |
| **Win + Ctrl + Fleche Droite/Gauche** | Naviguer entre les bureaux virtuels |
| **Win + Ctrl + F4** | Fermer le bureau virtuel actuel |

### 2. Raccourcis "Exécuter" (`Win + R`) - Consoles, CPL & Utilitaires

### Panneaux de Contrôle (`.cpl`)
- `ncpa.cpl` : Connexions réseau (Gestion des cartes réseau IP v4/v6).
- `sysdm.cpl` : Propriétés système (Nom de machine, Domaine/Workgroup, Variables d'environnement).
- `appwiz.cpl` : Programmes et fonctionnalités (Désinstallation/Modifications).
- `firewall.cpl` : Pare-feu Windows (Configuration basique).
- `main.cpl` : Propriétés de la souris (Pratique pour modifier le pointeur en bureau à distance).
- `mmsys.cpl` : Gestion des périphériques de son et audio.
- `powercfg.cpl` : Options d'alimentation (Mise en veille, gestion d'énergie).

### Consoles de Gestion (`.msc`)
- `services.msc` : Gestionnaire de services Windows.
- `compmgmt.msc` : Gestion de l'ordinateur (Observateur d'événements, Disques, Partages...).
- `devmgmt.msc` : Gestionnaire de périphériques.
- `diskmgmt.msc` : Gestion des disques et partitions.
- `eventvwr.msc` : Observateur d'événements système et sécurité.
- `lusrmgr.msc` : Utilisateurs et groupes locaux.
- `secpol.msc` : Stratégie de sécurité locale.
- `gpedit.msc` : Éditeur de stratégie de groupe locale (GPO locale).
- `fsmgmt.msc` : Dossiers partagés et sessions ouvertes.
- `wf.msc` : Pare-feu Windows avec fonctions avancées de sécurité.

### Utilitaires Admin & Autres (`Other`)
- `cmd` / `powershell` : Invites de commande et terminal de scripting.
- `control` : Ancien Panneau de configuration classique complet.
- `regedit` : Éditeur de registre Windows (HKLM, HKCU).
- `mstsc` : Connexion Bureau à distance (RDP).
- `mmc` : Console de gestion Microsoft vide pour créer sa propre console personnalisée.
- `cleanmgr` : Nettoyage de disque Windows.
- `%temp%` : Dossier des fichiers temporaires de la session utilisateur actuelle.
- `mrt` : Outil de suppression des logiciels malveillants de Microsoft.
- `msinfo32` : Informations système détaillées (Résumé matériel, BIOS, OS).
- `wsl` : Lancement direct de Windows Subsystem for Linux.
- `taskmgr` : Gestionnaire des tâches.
- `resmon` : Moniteur de ressources (CPU, Mémoire, Disque, Réseau en temps réel).
- `perfmon` : Moniteur de performances.
